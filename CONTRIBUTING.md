# Contributing: airdrop-works

This project-specific contributing guide extends /home/onceuponaprince/CONTRIBUTING.md.

## Defaults

- Keep changes scoped to this project unless cross-project work is explicitly requested.
- Preserve existing architecture, formatting, naming, and dependency choices.
- Do not mix unrelated refactors with behavior changes.
- Do not introduce new dependencies unless the task clearly requires them.
- Do not commit unless explicitly requested or required by project workflow.

## Local Workflow

- Detected stack:  JavaScript/TypeScript.
- Default package manager: project package manager unless project docs say otherwise.
- Branch naming: use existing project convention if present.
- Pull requests should describe what changed, why, validation performed, and known risks.

## Documentation

Update project docs when changing:

- Public behavior.
- Setup commands.
- Environment variables.
- Architecture boundaries.
- Test commands.
- Security assumptions.
