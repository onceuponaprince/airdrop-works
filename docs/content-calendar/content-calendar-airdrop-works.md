# AI(r)Drop — 4-week content calendar

**Product:** [airdrop.works](https://airdrop.works)  
**Period:** 26 May 2026 → 22 June 2026  
**Planned via:** Content Builder (`airdrop-marketing` profile) — see [`brief-for-content-builder.md`](./brief-for-content-builder.md)  
**North-star order:** waitlist completions → donations → paid signup (whitelist-gated)

---

## 1. Executive summary

AI(r)Drop’s content job for the next four weeks is to **prove the judge works**, **fill the waitlist with credible builders**, and **invite transparent support**—without over-promising token outcomes. Twitter/X carries daily proof and hooks; the blog carries one substantive argument per week. Every post maps to a single CTA: **Try demo**, **Join waitlist**, or **Support (donate)**.

**Primary KPIs**

| KPI | GA / signal | 4-week target (directional) |
|-----|-------------|-----------------------------|
| Demo → score | `marketing_demo_complete` / `marketing_demo_score` | ↑ week-over-week |
| Waitlist submit | `waitlist_submit_success` | Primary growth metric |
| Twitter wow → waitlist | `twitter_analyze_complete` → session waitlist | New loop post-ship |
| Donate | `donate_success` | Steady low-volume, high-trust |
| Pricing intent | `pricing_plan_click` | Feeds waitlist, not signup wall |

**Channel mix:** ~70% Twitter/X, ~25% blog (canonical depth), ~5% Discord/Telegram (announcements only until community infra is live).

## 7. Risks & guardrails

| Risk | Guardrail |
|------|-----------|
| Token / price speculation | No TGE dates, no “airdrop confirmed” language |
| Guaranteed returns | Never promise allocation, rank, or token amount |
| Signup wall confusion | All paid tiers point to **waitlist**, not `/signup` |
| Donate = access | Always state donation is separate from product access |
| Cookie / GA undercount | Treat GA as directional; watch server waitlist count |
| Analyzer on private individuals | Use opted-in handles or team accounts only |
| Mainnet donate errors | Only post donate CTAs after smoke script passes on prod |
