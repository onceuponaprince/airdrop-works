# Design Guidance: airdrop-works

This file should capture the product-specific design system for this project. Until expanded, preserve existing UI patterns, components, tokens, and brand direction found in the codebase.

## Defaults

- Do not impose a generic design language over an existing product identity.
- Prefer project-defined tokens, CSS variables, component primitives, and typography.
- Keep responsive behavior explicit for mobile and desktop.
- Preserve accessibility: semantic HTML, keyboard support, visible focus states, and sufficient contrast.
